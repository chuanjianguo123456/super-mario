# 超级马里奥游戏增强版

## 🎉 新增特性

参考了优秀的 [C++ 马里奥项目](https://github.com/ByteTuxiaobei/Mario) 的设计理念，在原有基础上新增了以下特性：

### 🔍 调试模式（按 F3 切换）
- ✅ 实时显示碰撞箱（玩家绿色、敌人红色、无害黄色）
- ✅ 可视化速度矢量（绿色箭头）
- ✅ 瓦片网格辅助定位
- ✅ 实时信息面板（位置、速度、状态、FPS、实体数）

### ✨ 粒子特效系统
- ✅ 收集金币时的星星粒子飞溅
- ✅ 踩踏敌人时的打击粒子效果
- ✅ 砖块碎片淡出动画
- ✅ 多彩粒子（金色、白色、蓝色）

### 📊 进度可视化
- ✅ 标题画面显示彩色进度条
- ✅ 已通关/总关卡数清晰展示
- ✅ 全通关时进度条变绿色

### 🎨 视觉增强
- ✅ 标题文字浮动动画
- ✅ 通关文字脉冲效果
- ✅ Boss 血条颜色分级（绿→橙→红）
- ✅ 时间紧急时多重警告（颜色+音效）
- ✅ 彗星能量倒计时闪烁提醒

### 🎵 音效改进
- ✅ 时间警告音效（≤100秒 和 ≤50秒）
- ✅ 所有音效由 Web Audio API 实时合成
- ✅ 无需外部音频文件

### ⚖️ 平衡性调整
- ✅ 玩家操控更灵活（微调物理参数）
- ✅ Boss 更具挑战性（血量+1、攻击频率提升、受伤加速）
- ✅ 敌人威胁性适度提升

## 🎮 操作说明

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 移动 |
| Z / 空格 | 跳跃 |
| X / Shift | 奔跑/发射火球 |
| P / ESC | 暂停 |
| R | 重新开始当前关卡 |
| M | 静音/开启声音 |
| **F3** | **切换调试模式（新）** |
| Enter | 开始游戏 |
| C | 继续到最后通关关卡 |

## 🚀 快速开始

### 在浏览器中运行
```bash
# 直接打开 index.html 即可
start index.html
```

### 桌面版（Electron）
```bash
npm install
npm start
```

### 打包 Windows 版
```bash
npm run dist:win
```
